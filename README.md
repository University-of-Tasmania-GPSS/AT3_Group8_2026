Project Overview 
An 87 cubic metre sinkhole was discovered at Sandy Bay's, Long Beach, prompting further study into how it got there and if other holes of similar characteristics in the Derwent river could 
be modeled
This project investigates coastal vulnerability and potential ground washout susceptibility at Long Beach, Sandy Bay, Tasmania, using Geographic Information Systems (GIS) and 
Python-based spatial analysis. The study combines coastal erosion vulnerability assessment with multicriteria washout susceptibility modelling to identify locations potentially 
requiring further investigation. 


The project consists of two complementary components: 
1. Coastal Vulnerability Assessment
An assessment of coastal vulnerability of the Derwent River estuary using a Coastal Vulnerability Index (CVI) and Fuzzy 
Gamma modelling to examine spatial variations in coastal exposure.

2. Washout Susceptibility Assessment
Eight susceptibility models were developed to investigate the influence of coastline proximity, 
surface drainage, terrain characteristics, coastal erosion hazards and soil erodibility on sinkholes in the Long Beach Area
